# Геозоны доставки (Москва / МО / МКАД)

В этой директории находятся **готовые к использованию геозоны** в формате GeoJSON, предназначенные для проверки условий доставки (логистика, тарифы, ограничения машин).

Файлы получены из данных **OpenStreetMap** и подготовлены для использования в backend-логике (point-in-polygon), а не для картографической визуализации.

---

## Состав файлов

### `mkad_polygon_simplified.geojson`
**Зона: MKAD**

- Полигон территории **внутри МКАД**
- Тип геометрии: `Polygon`
- Система координат: **WGS84 (EPSG:4326)**
- Назначение:
  - ограничение зоны загрузки (pickup)
  - автоматическое ограничение для радиусных спец-машин
- Упрощённая геометрия (simplified) — оптимизирована для быстрых проверок

---

### `moscow_mo_simplified.geojson`
**Зона: MOSCOW_MO**

- Полигон территории **Москва + Московская область**
- Тип геометрии: `Polygon`
- Система координат: **WGS84 (EPSG:4326)**
- Назначение:
  - ограничение зоны выгрузки (dropoff)
  - автоматическое ограничение для радиусных спец-машин
- Упрощённая геометрия (simplified)

---

## Источник данных

- Исходные данные: **OpenStreetMap**
- Формат источника: `.osm.pbf`
- Геометрии собраны из административных границ и дорожных объектов (МКАД)
- Полигон МКАД получен как область **внутри кольцевой дороги**

---

## Технические характеристики

- Формат: **GeoJSON**
- CRS: `+proj=longlat +datum=WGS84`
- Каждая зона содержит **ровно один Polygon**
- Размер файлов минимизирован для использования в production

Эти файлы **не предназначены для редактирования**.  
Если требуется изменить геометрию — пересобирайте зоны из исходных OSM-данных.

---

## Рекомендованное использование

### Backend (Python / Shapely)

- Загружать GeoJSON при старте приложения
- Преобразовывать в `shapely.geometry`
- Использовать `shapely.prepared.prep` для быстрых проверок:
  - `point ∈ polygon`

Типичные сценарии:
- проверка допустимости загрузки/выгрузки заказа
- фильтрация подходящих машин
- автоматические зональные ограничения для спец-транспорта

## Ограничения и допущения

- Геозоны основаны на данных OSM и могут не учитывать временные или юридические изменения границ
- Упрощение геометрии допускает погрешность на уровне метров, что допустимо для логистики
- Для навигации и маршрутов используется отдельный движок (например, OSRM)
